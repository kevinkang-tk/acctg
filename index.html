About LedgerQuest

A university accounting course project.

LedgerQuest is a gamified accounting education website that allows students to learn accounting through interactive business simulations. Rather than memorizing accounting rules through static exercises, users apply accounting concepts as they advance from Accounting Intern to CFO.

Learning goals

  • Apply accounting concepts to realistic business events.
  • Connect journal entries to financial statements.
  • Practice the complete accounting cycle.
  • Identify accounting errors and internal-control weaknesses.
  • Increase student engagement through game mechanics.

How it is built

  • HTML, CSS and vanilla JavaScript only.
  • No external API and no AI API.
  • No backend and no database.
  • All answer validation is rule-based.
  • Progress is stored locally in the browser.

Use of AI during development

Claude was used during the development process to assist with planning, interface design, and code generation. The deployed website does not connect to Claude, OpenAI, or any external artificial-intelligence API. All educational content, accounting logic, scoring, and answer validation run locally in the browser.

LedgerQuest is an educational simulation and does not provide professional accounting, audit, tax, or legal advice.
